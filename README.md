# 🌤️ Weather App

A simple and clean weather application built using **HTML** and **CSS**, powered by a live weather API. This app allows users to search for any city and view real-time weather conditions along with a 5-day forecast.

---

## 🚀 Live Demo

👉 https://pre-final-seven.vercel.app/

---

## 📌 Features

* 🔍 Search for any city worldwide
* 🌡️ Displays current temperature
* ☁️ Shows weather conditions (e.g., scattered clouds)
* 📅 5-day weather forecast
* 💨 Wind speed, 💧 humidity, and 🌡️ "feels like" temperature
* 🎨 Clean, minimal, and responsive UI

---

## 🛠️ Built With

* **HTML5** – structure of the app
* **CSS3** – styling and layout
* **SheCodes Weather API** – real-time weather data
* **Vercel** – deployment and hosting

## ⚙️ How It Works

1. User enters a city name in the search bar
2. The app sends a request to the weather API
3. Weather data is fetched and displayed dynamically
4. Forecast and additional details update instantly

## 🌍 Deployment

This project is deployed using **Vercel** for fast and reliable hosting.

To deploy your own version:

1. Push your project to GitHub
2. Go to Vercel
3. Import your repository
4. Click **Deploy**
